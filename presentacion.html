The Need

Why did we build this app?

Before

  • Old system SPW — only works on a desktop PC inside the store
  • Stock and sales visible only at the workplace
  • Slow customer service

Our Goal

  • Access business data from anywhere, at any time
  • Keep stock and sales records always up to date
  • Faster and more organized service
Objectives

General & Specific Objectives

General Objective

Develop a mobile application to facilitate product management, stock control and commercial operations for Nazareth Bookstore.

  • Easy product consultation and management
  • Better organization of inventory information
  • Search tools to find articles quickly
  • Integration with APIs and web services
  • Apply our knowledge of programming and software development
  • A real solution for a real client

Technology

How does it work?

📱 Mobile App

Built with Android Studio and Java. Simple, fluid and intuitive interface.

🖥️ Server

Django (Python) with a REST API that connects the app and the database.

🗄️ Database

Stores products, users and sales, synchronized in real time.

App ⇄ REST API ⇄ Django Server ⇄ Database

Final Product

What can the app do?

  • Login with roles — admin and seller, each with different permissions
  • Products — consult, add, edit and delete articles
  • Stock — always up to date and synchronized with the server
  • Sales — register commercial operations in a few taps
  • Search — find any product in seconds
